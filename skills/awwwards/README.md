# Vendored skill: awwwards

This folder vendors the MIT-licensed **awwwards** skill from
[SandroHub013/awwwards-skill](https://github.com/SandroHub013/awwwards-skill)
(Copyright © 2026 Alessandro Boni, see `LICENSE`).

It encodes the Awwwards jury rubric — Design 40 / Usability 30 / Creativity 20 /
Content 10 — as a phased build method: concept, art direction, signature moment,
build, craft, hardening, self-score and submission, with 19 reference files.

The FitQuest UI in `src/` was designed with this playbook: one signature moment
(the hero quest card), a token-first art direction (pine / bone / chartreuse /
apricot), editorial typography, a full craft and hardening pass, and a
real-browser audit at 320, 390, 768, 1024 and 1440 px.

To reuse it with an agent, keep `SKILL.md` and its `references/` together.
